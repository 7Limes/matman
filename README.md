# matman

A Material Management tool for game development.

matman converts existing PBR materials into ones that can be used in your favorite engine. Currently, the following platforms are supported:

- Unity (URP)
- Godot


## Features

- Convert .zip files and folders containing textures into materials compatible with game engines
- Browse and download materials from ambientCG and Poly Haven
- Batch resize material textures
